# Kiosk Companion

Build a React + TypeScript + Tailwind + shadcn app "KIOSK" for college touch kiosks and mobile. Navy (#0B1F6B) primary, gold accent, green for ERP success states. Touch rules: all buttons min 56px tall, 16px+ spacing, no hover-only actions, no typing where pickers/chips work, bottom nav on mobile, side nav on kiosk. Create only the layout shell, routing, and empty placeholder pages. Mock data only.
